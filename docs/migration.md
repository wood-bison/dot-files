# Решения и источники — 2026-09-29

## Актуальность платформы

- Homebrew указывает Apple Silicon macOS 15–27, включая Golden Gate, как поддерживаемую
  конфигурацию: [установка](https://docs.brew.sh/Installation),
  [уровни поддержки](https://docs.brew.sh/Support-Tiers).
- Homebrew Bundle по умолчанию обновляет перечисленные пакеты. Здесь передаётся
  `--no-upgrade`, если не запрошен `--upgrade`. Зависимости нового пакета всё равно
  могут потребовать обновления. [Документация](https://docs.brew.sh/Brew-Bundle-and-Brewfile).
- Ghostty поддерживает `light:...,dark:...`. У нас непрозрачный фон в обеих темах
  (`background-opacity = 1`, blur выключен), поэтому нет зависимости от обходных
  решений native-glass. Документация отмечает отдельную проблему оформления
  вкладок macOS при переключении темы; исправленной её здесь не объявляем.
  [Темы](https://ghostty.org/docs/features/theme),
  [параметры](https://ghostty.org/docs/config/reference).
- Zed поддерживает независимые системные пары тем и иконок:
  [темы](https://zed.dev/docs/themes),
  [оформление](https://zed.dev/docs/visual-customization).
- Шрифт доступен как [font-maple-mono-nf](https://formulae.brew.sh/cask/font-maple-mono-nf).

Документация обновляется со временем. Проверявшаяся локальная среда:
macOS 26.7, Zed 1.21.0, Ghostty 1.3.1. Запуск на Golden Gate в этой среде не проверялся.

## Изменения

- Fluent по умолчанию в Zed и Ghostty; Cameo — дополнительная тема Zed.
  Источники токенов и SVG Cameo нужны для воспроизводимой сборки.
- Один Fluent-генератор выпускает CSS, Zed JSON, Ghostty и иконки.
  Prompt, eza, fzf и delta используют ANSI-роли терминала.
- Убраны Cameo-профили терминала, шейдеры, переключатели палитр и polling launchd.
  Непрозрачный фон устраняет необходимость старых обходов прозрачности.
- Atuin, lazygit и Yazi исключены из установки. На исходном Mac старые управляемые конфиги
  материализованы перед удалением исходников; история/базы приложений сохраняются.
- Исторические HTML-аудиты, скриншоты, старые эксперименты и замены иконок
  приложений убраны из рабочего дерева. Предыдущие версии доступны в Git.
- Shell не подменяет ls/cat, не скрывает lockfiles глобально через ripgrep,
  не вызывает без проверки окружение Atuin и не содержит чужих абсолютных путей.
- Личные Pi/Sideshow, Wallgen, Mimo и Antigravity исходного Mac перенесены
  в его локальный shell-файл. На новый компьютер они автоматически не попадут.
- Git сохраняет identity, credential helpers, другие include и выбранный ignore.
  Прежние pull/push/undo-предпочтения старой установки остаются локально.
- Установленные конфиги — копии с контрольными суммами. Повторный запуск сохраняет
  последующие пользовательские правки; явная замена делает новый бэкап.
- Шрифты, keymap, диагностика и основные настройки редактирования Zed сохранены.
  Удалены старые настройки панели AI и противоречивые исторические комментарии.
  Языковые расширения перечислены для автоматической установки.

## Границы установки

Homebrew может запросить пароль администратора и установку CLT.
GitHub-аутентификация, системные разрешения и ответы в этих диалогах остаются за пользователем.
Режим `--config-only` предназначен для машины с уже установленными зависимостями.
При ошибке установки пакетов скрипт останавливается.

Скрипт не переключает оформление macOS и не завершает приложения принудительно.
Обновлённые ресурсы применяются через обычную перезагрузку конфигурации/приложения.

## Проверено в этой переработке

- 11 изолированных проверок установщика: повторный запуск, бэкапы, сохранение
  пользовательских правок, Git identity/includes, пути с пробелами и ранний отказ
  при повреждённом локальном JSON, оборванном `.gitconfig` или пропавшем старом Git include.
- Сборка и две установки из чистой копии исходников в отдельный тестовый каталог.
- Синтаксис bash/zsh и штатный `ghostty +validate-config`.
- В Zed наблюдалась светлая Fluent; после обычного перезапуска обе Fluent-темы
  иконок обнаружены, светлая выбрана. Визуальная проверка Ghostty недоступна
  из-за ограничения инструмента управления приложениями. В панели файлов Zed
  дополнительно проверено отображение собственных Fluent-иконок.

При переходе со старой версии сначала сохрани данные конфигов, на которые
указывали симлинки: `git pull` способен удалить их исходники. Новый установщик
останавливается при оборванном `~/.gitconfig` или отсутствующем старом Git include,
чтобы не потерять прежние настройки.
Для уже переведённого исходного Mac и новой установки этот шаг не нужен.

Homebrew в `.zshrc` добавляется только в недостающие элементы PATH: выбранный
SDKMAN JDK и личные команды сохраняют приоритет. Проверено изолированным запуском zsh.
