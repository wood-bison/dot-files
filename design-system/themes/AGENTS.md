# Theme families

Read README.md and the selected family's README before editing.
Keep families isolated. Never replace Cameo tokens, outputs, symlinks or active application settings when adding an alternative.
For Fluent Glass, edit tokens.json and run its build.py; generated files are not editable sources.
Preserve semantic role parity across appearances, reading accents and accessibility fallbacks. Verify actual target rendering before claiming visual acceptance. Zed adapters need Zed verification, independently of web QA.
Do not install or activate a theme without an explicit request to do so.
